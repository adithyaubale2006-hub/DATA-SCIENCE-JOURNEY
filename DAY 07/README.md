# DAY 7 — Decision Trees + Random Forest + XGBoost Basics

## Overview
This directory contains Day 7 of the Data Science Journey, focusing on tree-based machine learning models.

## Contents
- **DAY_7.ipynb** - Complete Jupyter notebook with:
  - Decision Trees fundamentals
  - Gini Impurity explanation
  - Random Forest implementation
  - XGBoost classifier
  - Professional evaluation metrics
  - Model comparison and confusion matrix visualization

## Key Topics Covered
1. **Decision Trees** - Understanding how trees split data
2. **Random Forest** - Ensemble learning with multiple trees
3. **XGBoost** - Gradient boosting for improved performance
4. **Evaluation Metrics** - Accuracy, Precision, and Recall
5. **Confusion Matrix** - Detailed performance analysis

## Dataset
The notebook uses a Social Media Ad Click dataset with:
- Features: Age, Daily_Time_Spent
- Target: Clicked (0/1 classification)
