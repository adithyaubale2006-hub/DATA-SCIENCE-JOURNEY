# Time Series Forecasting with Machine Learning

A beginner-to-intermediate Machine Learning project focused on Time Series Analysis and Forecasting using Python, Pandas, and Scikit-learn.

## Overview

This project demonstrates how to:
- analyze time series data
- create forecasting features
- train ML forecasting models
- predict future values

The workflow includes:
- lag features
- rolling statistics
- momentum analysis
- volatility analysis
- Random Forest forecasting

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## Features Engineered

- `lag_1`
- `lag_2`
- `rolling_mean`
- `rolling_std`
- `momentum`
- `ewm`

## Machine Learning

Model Used:
- `RandomForestRegressor`

Evaluation Metrics:
- MAE
