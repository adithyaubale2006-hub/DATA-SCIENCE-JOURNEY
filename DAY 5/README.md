#  Exploratory Data Analysis (EDA) Project

##  Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a customer dataset to understand:

* customer demographics
* income distribution
* spending behavior
* correlations between features
* business insights from data

The goal of this project is to practice:

* data understanding
* statistical analysis
* visualization
* business storytelling

---

#  Dataset Information

The dataset contains:

| Column         | Description                |
| -------------- | -------------------------- |
| Customer_Age   | Age of customer            |
| Income         | Annual income              |
| Spending_Score | Customer spending behavior |
| Gender         | Male/Female                |

---

* Python

# 📊 EDA Steps Performed

## 1. Data Understanding

* `head()`
* `info()`
* `describe()`
* `shape`

---

## 2. Univariate Analysis

Analyzed:

* Income distribution
* Spending score distribution

Visualizations:

* Histogram
* Boxplot

---

## 3. Categorical Analysis

Analyzed:

* Gender distribution

Visualizations:

* Countplot
* Value counts

---

## 4. Bivariate Analysis

Studied relationships between:

* Income vs Spending Score
* Age vs Income

Visualization:

* Scatter plots

---

## 5. Correlation Analysis

Created:

* Correlation matrix
* Heatmap

Purpose:

* identify strong relationships between variables

---

#  Key Insights

## Insight 1

Customers with higher income generally show lower spending scores.

---

## Insight 2

Middle-aged customers contribute significantly to overall spending.

---

## Insight 3

Income and spending behavior show noticeable variation across customers.

---

## Insight 4

Some high-income customers have surprisingly low spending scores, indicating potential untapped business opportunities.

---

## Insight 5

The dataset contains balanced customer demographic information useful for segmentation analysis.
