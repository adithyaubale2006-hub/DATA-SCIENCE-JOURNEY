# DAY 3 — Advanced Pandas + Feature Engineering

## 🎯 Goal

Learn advanced Pandas operations and create Machine Learning-ready features using time-series data.

## 📚 Topics Covered

### 🐼 Advanced Pandas
- `shift()` - Shift values within a Series or DataFrame
- `rolling()` - Apply rolling window calculations
- `diff()` - Calculate first discrete difference
- `pct_change()` - Percentage change between elements
- `expanding()` - Expanding window calculations
- `ewm()` - Exponential weighted moving window

### ⚡ Feature Engineering
- **Lag Features** - Use previous time steps as features
- **Moving Averages** - Smooth data with moving windows
- **Momentum** - Capture rate of change
- **Volatility** - Measure price/value fluctuations
- **Exponential Moving Average (EMA)** - Weighted moving averages

### 📅 Datetime Feature Engineering
- Year extraction
- Month extraction
- Weekday extraction
- Date conversion

## 🛠️ Skills Learned
- Time-series analysis
- Financial feature engineering
- Forecasting preparation
- ML-ready dataset creation
