#  Data Cleaning & Preprocessing Project

This project demonstrates essential data cleaning and preprocessing techniques used in Data Science and Machine Learning.

## Topics Covered

* Handling missing values
* Removing duplicates
* String cleaning
* Datatype conversion
* Outlier detection using IQR
* Feature scaling
* Encoding categorical data
* Train-test split
* Basic preprocessing pipeline

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Workflow

1. Load dirty dataset
2. Detect missing values
3. Clean and preprocess data
4. Handle outliers
5. Encode categorical columns
6. Scale numerical features
7. Prepare dataset for Machine Learning

## Features Implemented

* `fillna()`
* `drop_duplicates()`
* `StandardScaler`
* `LabelEncoder`
* `IQR Outlier Detection`
* `train_test_split`

## Goal

To build a clean, ML-ready dataset from raw real-world data.
